WURM HIGH-RES ICONS 0.1.39
By Chamomilo

Detailed 32 x 32 interface icons for the Wurm Unlimited client, material-aware
tools and shields, separate artwork for supported shared-icon items, animated
rarity highlighting and magic-item shimmer.

Illustrated README, screenshots and settings:
https://github.com/chamomilo/wurm-high-res-icons#readme
Downloads:
https://github.com/chamomilo/wurm-high-res-icons/releases/latest
Issues:
https://github.com/chamomilo/wurm-high-res-icons/issues

INSTALLATION
Requires Ago's Client ModLauncher for Wurm Unlimited:
https://github.com/ago1024/WurmClientModLauncher/releases

1. Close the game client.
2. Extract this ZIP into your WurmLauncher folder. Keep the mods structure.
3. Replace the old mod configuration, or merge custom settings manually.
4. Start the client through Client ModLauncher.

SETTINGS
Edit mods/wurm-highres.properties while the client is closed, then restart.
replaceIcons=true       Replacement item artwork.
rarityGlow=true         Rare, supreme and fantastic highlights.
rarityBackground=false  Coloured background behind rare items.
rarityAnimation=blob    Choose blob or star.
pulseGlow=true          Pulsing white shimmer.
magicShimmer=true       Magic water skin and Santa sack effects.
rareColor=66,153,224
supremeColor=0,255,255
fantasticColor=255,0,255
Colours accept RGB values or hex colours. glowRadius, glowAlpha and
backgroundAlpha control the highlight size and opacity.
